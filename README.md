# Timur Thermal Printer

Мобільний генератор PNG-чека для iPhone та міні-термопринтера.

Функції:
- дата, день тижня та поточний час;
- погода через Open-Meteo;
- мін/макс температура, ймовірність дощу та вітер;
- схід/захід сонця;
- державні свята Rheinland-Pfalz;
- українська та німецька мови;
- PNG 384 або 576 px;
- власний текст унизу;
- збереження/поширення PNG на iPhone.
