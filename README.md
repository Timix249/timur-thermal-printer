# Timur Thermal Printer v2

Мобільна PWA для створення PNG-чеків для термопринтера.

## Функції
Погода, температура, «відчувається», дощ, вітер, схід/захід сонця, свята Rheinland-Pfalz, дата, час, українська/німецька, 384/576 px, власний заголовок і нотатка, розмір тексту, вирівнювання, рамка, розділювачі, контраст, геолокація, запам'ятовування налаштувань, автооновлення, офлайн-кеш, PWA manifest та іконки.

## Встановлення на iPhone
Відкрийте сайт у Safari → Поділитися → На початковий екран.

## Важливо про Фото на iPhone
Звичайний вебсайт/PWA не має системного дозволу тихо записувати PNG прямо в медіатеку Photos. Кнопка «Зберегти PNG» завантажує файл без Web Share меню. Для повністю автоматичного запису в Photos потрібна нативна iOS-програма або Shortcut.
